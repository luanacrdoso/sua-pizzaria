# PizzaShop PWA

## Como rodar

```bash
npm install
npm run dev
```

Depois abra o endereço que aparecer no terminal (normalmente http://localhost:5173).

Para gerar a build de produção:

```bash
npm run build
npm run preview
```

Veja `CORRECOES.md` para o detalhe de tudo que foi corrigido/ajustado nesta versão.
